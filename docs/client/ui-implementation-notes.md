# Решения p24–p37

API: новые функции связывают ключ карты `Endpoints` через `core/api/endpoint.ts`. Транспорт кодирует параметры пути, сохраняет query, workspace, AbortSignal и keepalive; тело и ответ новых функций берутся из контракта. Существующие позиционные API сохраняют совместимые сигнатуры и получают тип ответа из `Endpoints[ключ]['response']`. Серверные расхождения исправлены по обработчикам маршрутов: фильтры библиотеки, projectId у detach/exclude, own_credential, состояния ревью/подготовки, разрешения чата и значения resolution. Доменные подписки принадлежат tasks/code; транспорт передаёт сообщения без знания доменов.

UI: новые примитивы и shared переведены в рамках p24–p37. Массовая замена контролов, вкладок, бейджей и карточек фич остаётся в p38–p43. Исключения текущих шагов: дифф предложений библиотеки, CoauthorsField, замена импортов удалённого PlainSelect и общих SVG-иконок. Legacy-стили сохраняются до p44 для ещё не переведённых экранов.

WorkStages остаётся отдельным представлением процесса: этапы показывают доступность, пропуски, выполнение и изменения документов. Это не обычный список вкладок. При миграции tasks в p39 общая навигационная часть может использовать AppTabs; вычисление состояний и StageMark остаются в WorkStages.

Иконки SVG берут currentColor. Многоцветные иконки файлов из существующего набора остаются графическими ресурсами code-viewer.

Проверки примитивов: `npm run test:ui-primitives`. Они проверяют поведение ссылок, поповеров, выбора с клавиатуры, совместимость FormField, дифф и транспорт. Полный прогон UI и автоматические ограничения относятся к p45–p47.

Проверено 2026-11-04: 19 тестов примитивов, библиотеки и подготовки прошли; общая типизация и сверка 306 маршрутов прошли; ESLint — без ошибок. Production-сборка проходит с предупреждениями Rollup о циклических зависимостях чанков и размере пакетов.

Для p47: дополнительные старые наборы `code-client`, `code-git`, `chat-drafts` пока не зелёные (15 успешных, 23 неуспешных). Их ручные загрузчики и моки ожидают прежние пути API/подписок и не обрабатывают новые публичные импорты, CSS и `?raw`. Эти тестовые загрузчики в текущих шагах не переписывались. Переподключение и подсчёт подписчиков нового code/events отдельно проверяются в `ui-primitives.test.cjs`.
